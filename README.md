# UD01_Actividad05_CajeroAutomatico
 
Aplicación de consola en Kotlin que simula un cajero automático. Permite consultar el saldo, ingresar dinero y retirar dinero desde un menú interactivo.
 
## Tecnologías
 
- Kotlin
- IntelliJ IDEA
 
## Funcionalidades
 
- Consultar saldo
- Ingresar dinero
- Retirar dinero
- Salida del programa

## Instalación y ejecución
 
1. Clona el repositorio:
```bash
   git clone https://github.com/SergioGonMar31/CajeroAutomatico.git
```
2. Abre el proyecto en IntelliJ IDEA.
3. Ejecuta el archivo `Main.kt`.
